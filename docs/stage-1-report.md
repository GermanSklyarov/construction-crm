Дата: 4 ноября 2026 года.

- `supabase/tests/security.test.sql` — pgTAP-проверки доступа и бизнес-правил; rollback fixtures.

- `scripts/test-api.mjs` — временные Auth-пользователи и прямые HTTP-запросы.

- `docs/database-security.md` — матрица требований, схема, полный список политик, безопасность, допущения.

### Непроверенное и ограничения

Все 14 обязательных сценариев этапа 1 проверены на локальной базе. Не проверялись: hosted Supabase и его Auth-настройки, UI, production-деплой, нагрузочное тестирование. Случайные interleaving всех возможных запросов не перебирались; проверены три конкретные конкурентные операции с подтверждённым ожиданием блокировки.

Объект с задачами удалять нельзя. Профили и роли создаёт доверенный администратор. Исполнитель обязателен; описание может быть пустым. Изменение роли назначенного исполнителя блокируется FK. Доступ к истории следует за текущим назначением задачи. Полномочия владельца БД находятся вне модели угроз пользовательского API.

Тестовые Auth-аккаунты и данные удаляются после запусков; парольные и ключевые значения не записаны в файлы проекта. Локальные сервисы Supabase оставлены работающими для дальнейшего review; остановка — `npm run db:stop`.
