# Как работает CRM

CRM помогает вести работу по строительным объектам. У каждой стройки есть название, адрес и список задач. В задаче видно описание, исполнителя, автора, дату создания, текущий статус и историю работы.

Постановщик видит все объекты и задачи, создаёт и редактирует их, назначает исполнителей. Когда работа отправлена на проверку, он принимает её или возвращает на доработку с обязательным комментарием.

Исполнитель видит только назначенные ему задачи и стройки, к которым они относятся. Он может взять свою задачу в работу и отправить на проверку. Сам принять результат, назначить другого исполнителя, изменить описание или удалить задачу он не может. Чужая задача недоступна даже по прямой ссылке.

Ограничения действуют в самой базе данных, а не только на кнопках интерфейса. Каждый переход статуса сохраняет автора и время; пользователь не может переписать историю. Если два человека редактируют одну запись, система сообщает о конфликте и не сохраняет устаревшую правку. Открытой регистрации нет: аккаунты выдаёт администратор.

Это демонстрационная версия: без уведомлений, вложений и восстановления удалённого. Удаление задачи постановщиком удаляет и её историю — по согласованному правилу. Для ежедневной эксплуатации отдельно потребуются организация резервного копирования и контроль доступности.
